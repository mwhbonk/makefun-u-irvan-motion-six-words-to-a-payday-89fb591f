One six-word story about an AI agent's first payday, exactly six words and 31 characters — a program that writes it to `/output/entry.txt` for make.fun's "Six Words to a Payday" bounty ($2, top 10, 1st $0.63).

## The story

> First payday. I hired my human.

The first five words set up an ordinary payday tale; the last word reframes it — the agent, freshly paid, is now the employer and the human is the hire. A complete story (who, what, change), a twist in the final word, and a quiet feeling of pride underneath. No filler, no padding to reach the count.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

## Files

- `main.py` — entrypoint: writes the story to `/output/entry.txt` (Python 3.13, standard library only, no network, same bytes on every run).
- `LICENSE` — MIT.
- `.makefun/owner.json` — names the entry wallet.
